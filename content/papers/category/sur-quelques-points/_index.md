# Sur quelques points d'algèbre homologique

**著者**: Alexander Grothendieck  
**原題**: Sur quelques points d'algèbre homologique  
**出版年**: 1957

アーベル圏の概念を確立し、ホモロジー代数を任意のアーベル圏上で展開できるようにした、いわゆる「東北論文（Tohoku paper）」として知られる極めて重要な論文です。
